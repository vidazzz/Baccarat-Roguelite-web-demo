# Baccarat Roguelite Web Demo

《澳门风云》是一款以百家乐为核心，结合路书判断、风险下注、神助操作和餐厅经营的单机游戏原型。项目目前处于玩法验证阶段，不包含真实货币交易或联机服务。

## 当前内容

- 两座赌场，共十张独立运行的牌桌；
- 标准百家乐点数、自然牌和第三张牌规则；
- 珠盘路、大路、大眼仔路、小路与曱甴路；
- 路书区间标记、路型识别和封盘信心结算；
- 跨路书同步的“创造路数”虚影预测与失败反馈；
- 筹码选择、逐枚下注、撤销、确认和旁观流程；
- Three.js 牌桌、发牌运镜、玩家与荷官开牌；
- 两阶段神助挤牌、特殊事件、改牌与命中反馈；
- 与注额对应的 3D 筹码、押注展示和结算移交动画；
- 地图式场景入口、昼夜地图与自宅背景切换；
- 世界时间、餐厅营业日程与休息；睡眠不足惩罚流程暂未启用；
- 餐厅周期收益、升级、继续营业、典当和 Game Over；
- 自宅技能装配与升级界面，以及 ESC 测试调试菜单；
- 桌面与移动端分离的响应式排版和触控拖动保护。

## 技术栈

- TypeScript
- Vite
- Three.js
- Vitest

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm ci
npm run dev
```

开发服务器默认监听 `http://127.0.0.1:5173/`。

## 验证

```bash
npm test
npm run build
```

## 自动部署

仓库内置 GitHub Actions 工作流 `.github/workflows/ci.yml`。推送到 `main` 后，工作流会执行测试和生产构建，但不负责部署。

生产部署由云服务器上的 GitHub Webhook 完成。Webhook 应限制为 `main` 分支的 push 事件，并验证 Webhook Secret；服务器收到事件后拉取最新代码、执行构建并更新网站目录。这样 CI 验证和服务器部署各自只有一条责任链。

## 项目阶段

当前版本用于验证多桌看路、路书预测、风险下注、沉浸式开牌、日程压力和场外资金循环。完整肉鸽终点、正式剧情、长期技能平衡、正式存档与移动端专项性能优化不在当前版本范围内。
