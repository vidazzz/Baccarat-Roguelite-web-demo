# 《澳门风云》MVP 游戏设计文档

## 1. 文档信息

- 阶段：玩法验证 / MVP
- 状态：持续迭代
- 核心类型：百家乐、肉鸽成长、轻量模拟经营
- 目标平台：桌面端优先，MVP 以浏览器运行

本文档记录当前已确认的玩法规则。所有具体经济数值均为建议初值，需通过试玩与模拟调整。

> 2026-08 规则版本：连战、筹码经济和临时千术规则覆盖此前的单局现金下注、手动画路和永久技能设定。

## 2. 游戏概念

玩家经营一家能够持续产生收入的餐厅，同时进入不同等级的赌场参与百家乐。玩家观察多张牌桌各自形成的路单，寻找适合自身技能构筑的牌路，下注后通过搓牌亲自揭晓关键牌。

本作世界中，赌徒总结的“路数玄学”是真实规律：特定历史结果会令后续结果发生概率偏移。玩家掌握的技能能够进一步改写开牌概率，因此核心能力不是单纯提高胜率，而是识别局势、选择牌桌并在合适时机承担风险。

## 3. 核心体验

### 3.1 体验支柱

1. **观察与择桌**：多桌同时运行，玩家需要从图形化路单中寻找机会。
2. **概率操纵**：路数和技能真实影响结果，但不保证必胜。
3. **亲手揭晓**：通过搓牌逐步获得信息并释放胜负悬念。
4. **资金取舍**：赌资既可继续下注，也可投入餐厅换取长期收益；走投无路时可以典当家底。

### 3.2 核心体验语句

> 在多张不断变化的牌路中寻找自己最擅长的趋势，用成长出的赌术把玄学变成优势，并不断决定继续下注、带钱离场，还是押上家底。

## 4. 游戏循环

### 4.1 核心赌局循环

```text
城市地图选择赌场
  -> 浏览同步运行的牌桌和路单
  -> 选择牌桌
  -> 观察或下注
  -> 封盘后结算路数与技能造成的概率偏移
  -> 按百家乐规则发牌
  -> 玩家搓开关键牌
  -> 结算并更新路单
  -> 留桌、换桌或离场
```

### 4.2 外部资金循环

```text
餐厅周期收益/抵押 -> 可用筹码 -> 赌场下注 -> 赢钱返还现金
       ^                         |
       |                         v
       +---- 投资升级餐厅 <- 离场资金

餐厅典当 -> 获得最后一笔流动资金 -> 继续赌局或彻底破产

城市地图 -> 餐厅经营 / 赌场 / 自宅休息与技能管理
```

地图是玩家进入游戏后的主界面。返回地图只改变当前操作界面，不立即改变玩家正在进行的活动；只有从地图选择另一个地点，才切换实际活动并应用对应的时间、营业和赌场规则。

### 4.3 游戏失败

当玩家失去全部流动资金，且餐厅等可典当财产均已典当后，游戏结束。

完整肉鸽流程的终点暂不定义，不属于本次 MVP 的验证目标。

## 5. 赌场系统

### 5.1 赌场数量

MVP 至少包含两座赌场。赌场大厅使用 2D 图形界面，不制作完整 3D 场景。

| 属性 | 初级赌场 | 高级赌场 |
| --- | --- | --- |
| 定位 | 学习、积累与恢复资金 | 高风险、高资金波动 |
| 建议桌数 | 4 桌 | 6 桌 |
| 最低下注 | 较低 | 较高 |
| 最高下注 | 较低 | 较高 |
| 单次门票 | 100 | 1,000 |
| 视觉风格 | 朴素、信息清晰 | 更华丽但保持可读性 |

玩家每次从赌场选择界面进入赌场时支付一次门票；在该赌场内部往返大厅和牌桌不重复收费。门票使用唯一筹码余额支付，筹码不足时不能进入。

两个赌场均采用设计指定的两倍赔率，庄、闲不区分赔率。等级差异来自门票、下注上下限、牌桌数量和视觉主题。

具体金额在经济模型完成后确定。

### 5.2 多桌运行

- 每张牌桌拥有独立的历史结果、路单、下注倒计时和当前局状态。
- 玩家不在场时，牌桌仍持续产生结果。
- 玩家可以在大厅直接比较各桌，但不能在大厅下注。
- 玩家进入具体牌桌后，可以下注，也可以只观看。
- MVP 中所有后台牌桌只进行数据模拟，不渲染后台 3D 牌局。

### 5.3 图形化牌桌选择

赌场大厅中的每张桌以可点击的牌桌单元呈现，至少包括：

- 牌桌图形和桌号；
- 当前状态与封盘倒计时；
- 最低和最高下注；
- 与牌桌一致的压缩路纸（珠盘路、大路和下三路）；
- 当前已识别路势的图形提示；
- 进入牌桌操作。

界面的第一目标是让玩家快速扫视和比较多桌，不使用纯文字列表代替牌桌与路单。

## 6. 路单与路势

### 6.1 MVP 路单

MVP 实现以下五类百家乐路单：

1. **珠盘路**：按时间顺序排列每局结果。
2. **大路**：用列结构表现连续同侧获胜与庄闲切换，是技能判断的主要依据。
3. **大眼仔路**：以空心红蓝圆表现大路列结构是否齐整。
4. **小路**：以实心红蓝圆表现更远一列的齐整关系。
5. **曱甴路**：以红蓝斜杠表现更远两列的齐整关系。

建议使用行业常见的颜色和符号：

- 红色：庄赢；蓝色：闲赢；绿色斜杠：大路和局叠加标记；
- 大眼仔路为空心圆，小路为实心圆，曱甴路为斜杠。

大厅每张牌桌独占一行，并显示与正式牌桌一致的压缩路纸；具体牌桌内使用赌场常见的路纸排版：珠盘路、大路、大眼仔路、小路和曱甴路分区排列，同时显示牌局统计。问路栏当前已移除。

路纸图标遵循赌场常用表达：大眼仔路使用红、蓝空心圆，小路使用红、蓝实心圆，曱甴路使用红、蓝斜杠。大路中的和局不独立占格，而是在最近一次庄或闲结果的空心圆上叠加绿色斜杠；连续多次和局在斜杠旁显示累计次数。

### 6.2 MVP 路势

首版至少支持：

- 长庄：庄连续获胜；
- 长闲：闲连续获胜；
- 单跳：庄闲持续交替。

路势由历史结果触发，并真实改变下一局概率。玩家需要通过游玩学习这些规律。界面可以提示已识别的路势，但不直接替玩家给出下注答案。

## 7. 技能与概率系统

### 7.1 核心原则

最终结果由基础路势偏移与神助共同形成；信心只决定神助是否发动：

```text
基础百家乐概率
  + 当前牌桌的路势偏移
  = 初始牌局分布

下注封盘
  -> 结算下注风险、标记路数、逆势惩罚和连胜
  -> 得到本局信心，即神助触发率
  -> 最后一张牌可能触发神助
  -> 两阶段连点挤牌尝试改写暗牌
```

- 路数在没有技能时也会造成概率偏移。
- 信心只增加神助触发概率，不改变神助发动后的阶段命中率或改牌效果。
- 概率优势不等于确定结果，玩家始终可能在优势局中失败。
- 已公开的牌永远不能改写；每个发牌阶段的最后一张暗牌允许在神助结算时改写一次。
- 结果生成后，具体牌序必须符合百家乐发牌与补牌规则。

### 7.2 MVP 技能

首版保留三项与基础路势同主题的成长入口：

| 技能 | 主题路数 | 当前 MVP 状态 |
| --- | --- | --- |
| 长庄术 | 连续庄赢 | 可装配、升级，数值效果待接入 |
| 长闲术 | 连续闲赢 | 可装配、升级，数值效果待接入 |
| 单跳术 | 庄闲交替 | 可装配、升级，数值效果待接入 |

具体技能与新增路数类型的对应关系、数值和升级曲线待后续平衡。当前信心验证先以玩家手动标记有效路数为准，技能界面不得暗示技能等级已经修改信心。

- 当前只有一个技能栏位，玩家可以不装备技能，或在技能管理界面切换唯一的已装备技能。
- 技能管理界面提供装配、卸下和升级操作；升级消耗现金，MVP 最高 5 级。
- 当前技能等级保留装配、升级和成长入口，但不直接进入信心或神助效果公式；后续技能与完整路数类型的对应关系另行平衡。

### 7.3 信心与神助

当前版本神助触发率直接读取本局封盘时计算出的信心值，并限制最高 30%；不再额外重复计算筹码、路数或连胜加成：

```text
min(30%, 本局计算后的信心值)
```

只有在刚翻开的牌已经让下注目标成为必输结果时才检查神助。神助只允许重抽当前刚翻开的这一张牌；重抽改变补牌条件时，从该牌开始重新执行后续补牌和结算。

当前正式界面只保留大路和珠盘路。原有下三路、手动标记路数和创造路数暂时移除；下注方向与当前路数预测一致时，自动视为选中该路数。

- 每个下注局从 0% 基础信心重新结算，结果限制在 0% 至 100%；调试菜单可调整基础信心，也可单独锁定为 100%。
- 下注金额占封盘前流动现金每满 10%，信心增加 5%。餐厅典当价值不计入本次下注占比。
- 珠盘路按六行逐列持续落格；显示区域用满后新起一列，并把较早记录整体向左推出。历史裁剪不得使最后一局固定在某个格位。
- 点击珠盘路始终标记整张珠盘路，无论当前是否形成有效路数。珠盘路使用下一局即将落入的格子作为预测基准：从下一格所在行向左回溯，连续出现 4 个相同结果时形成金刚庄或金刚闲；珠盘路单跳也从该行的下一格向左倒推。
- 除珠盘路上述“下一格所在行”规则外，其他路数都必须以最后一局为终点向前识别连续后缀；历史中较早形成、但没有延续到当前预测位置的图形不参与预测。大路和下三路通过点击标题栏中与目标列对应的位置完成标记；只有精确点中当前有效后缀的起始列，标记才产生信心增益。点在起始列之前不能因观察区间包含有效后缀而生效，点在起始列之后则因路型不完整而失效。
- 下三路以红蓝图标识别长路、单跳、逢红/蓝连、逢红/蓝不连和不长过 N 口。成型路数预测的是下一枚红蓝图标，再通过庄问路、闲问路反推唯一对应的下注方向；两边问路颜色相同、无法唯一反推时，不产生信心效果。
- 只有有效标记路数预测方向与押注相同时，才获得每个路数 5% 的加成。
- 标记操作本身不能向正式玩家透露路数是否成立；所有路书无论识别结果都显示相同的标记反馈。玩法验证阶段允许额外显示明确标注为 `DEBUG` 的有效路数、预测方向和失败原因，该信息必须能够在正式版本关闭。
- 每份路书在当前预测位置最多只能成立一个有效路型。识别器可以在内部发现多个重叠候选，但必须按“路书专属型、长路、单跳、逢某方连/不连、不长过 N 口”的顺序归类并只保留一个；更早结束或与最终分类重叠的候选不参与信心结算。
- 标记路数从长度 2 起，每增加一级长度额外增加 2%。长路以 5 局为长度 1、其后每局加一级；单跳以 6 局为长度 1、其后每两局加一级；逢庄/闲连以 4 局为长度 1、其后每局加一级。未单独规定的路数暂按每增加一个确认单位加一级。
- 无论是否标记，只要当前牌桌存在有效路数，押注其预测结果的对家时，每个相反预测路数扣除 5%。押和不触发庄闲路数的增益或惩罚。
- 每延续一局下注连胜增加 1%；和局退注不终止连胜，亏损时归零。
- 前一天下注净盈利时形成天连胜，每连续一个盈利日增加 5%；当前 MVP 的“总体盈利”按已结算赌局净收益统计。
- 旁观局不进行上述信心结算，并使用基础信心。
- 信心只在确认下注、封盘进入牌局时结算并公开。在选择筹码、落注和标记路书期间不预览变化结果。
- 通用路数包括长路、单跳、逢庄/闲连、逢庄/闲不连、庄/闲不长过 N 口；珠盘路单独识别金刚庄/闲和珠盘路庄/闲单跳；大路额外识别 1324 交替和 2121 交替（两房一厅）。不同路书各自识别出的唯一有效路型可以叠加，同一本路书内部不能叠加。
- 玩家可以在任一路书的合法下一格上创建庄或闲预测，其他路书同步生成对应虚影；可连续向后创建，修改前一局会撤销其后的全部预测。实际结果与首个预测不符时，清空整段预测并扣除信心，结算后显示可点击关闭的失败反馈。
- 初始四张牌的最后一张，以及每一张后续补牌，分别拥有一次神助检查机会。
- 信心值是神助触发概率。旁观局不触发神助。
- 路数只负责预测下一局庄闲走势并形成信心，不参与神助触发后的求牌和喊牌；已下注时，100% 信心必定触发神助。
- 神助的目标恒定为玩家实际下注的结果。玩家押庄就求能令庄胜的牌，押闲就求能令闲胜的牌，押和就求能形成和局的牌。
- 玩家或荷官确定最后一张牌的开牌方式、镜头推进聚焦完成后，才判定并发动神助；不再等到普通眯牌或翻牌动画进行到中段。
- 发动时先播放 1 秒全屏冲击反馈，文案为“这张牌！我感觉到了！！”，随后进入牌型选择。
- 第一阶段选择“公、没边、两边、三边、四边”之一，从短边开始连点挤牌。牌面进度会持续回退且越接近完成回退越快，每次点击抵抗回退；第一阶段完成线为短边开牌进度的 30%。
- 第一阶段完成后以固定阶段概率尝试把当前暗牌改成所选类型中的合法随机牌。若结果已经足以令玩家下注方向获胜，则直接完成开牌；否则盖回并进入第二阶段。
- 第二阶段选择“吸”或“吹”，从长边继续连点挤牌，完成后尝试在合法候选中锁定玩家下注结果；“吸”偏向高点牌，“吹”偏向低点牌。
- 两阶段开始前均显示“狂按！”提示，玩家点击任意位置后正式开始。连点过程中不显示进度条，手指遮挡物不移开。
- 点击喊字在屏幕中央区域、纸牌之外随机出现，字号随机且随完成度变大；闪光、屏震和移动端触觉反馈同步增强。
- 神助目标牌真正翻开后，必须在当前牌面特写镜头尚未移走时立即显示本次神助概率是否命中。命中与落空使用不同的全屏强反馈，默认停留 1 秒后继续，玩家也可以点击任意位置提前关闭；提示关闭后才执行回桌运镜。
- 神助只能改写当前尚未公开的最后一张牌，且候选牌值必须保持既定补牌结构合法。
- 单局发动至少三次神助且最终获胜时触发特殊事件。玩家从“预言下次庄闲、预言下次结果、预言下次行为”中三选一，效果只作用于下一局并在使用后消耗。

### 7.5 荷官资金与临时千术

- 每张牌桌拥有独立荷官资金，初始及每个游戏日重置为 `¥10,000`。
- 玩家赢钱会消耗荷官资金；荷官资金降到 0 时触发一次随机抵押奖励。
- 当前奖励池只包含筹码和临时千术。
- 每日开始随机获得 2 个临时千术，额外奖励的千术也只在当天有效；第二天全部清除并重新抽取。
- 出千每次消耗 1 枚筹码。千术按钮在可用筹码不足 1 枚时仍可点击并立即提示所需费用，但不会进入选牌、指定边数或牌张调换阶段。连战中的出千属于全局操作：选择千术后可直接点击任意牌局的合法目标牌，包括已结算牌局中仍符合条件的明牌，不依赖当前显示或操作的牌局。
- 当前临时千术包括：透视盖牌（查看盖牌但不翻开）、重排盖牌（进入全局重排阶段，拿起所有牌局中的己方盖牌，并可跨牌局以任意顺序进行调换）、指定边数（先选择任意牌局的一张盖牌，再选择公、没边、两边、三边或四边；系统从所选类型中随机抽取一张替换该盖牌）、重抽明牌（重抽一张明牌）和调换明牌（从所有牌局中选择两张己方明牌，只交换一次）。任何改牌千术完成后，所有受影响的已结算牌局立即按新牌面重新结算。
- 透视盖牌以半透明蓝色遮罩覆盖牌面，明确表示“已透视但仍是盖牌”；真正开牌前恢复牌背，再进入当前统一的自动翻牌动画。

### 7.4 待验证规则

以下内容尚未定案：

- 技能全部被动触发，还是包含需要玩家主动发动的强力技能；
- 玩家能否看到精确概率；
- 和局是否接受玩家下注；
- 是否在 MVP 中实现庄抽水、对子等附加规则。

在实现前应为这些规则提供配置能力，避免写死在界面逻辑中。

## 8. 下注与结算

### 8.0 连战

- 进入牌桌后不单独选择连战局数；牌桌只配置最大连战轮数。玩家完成一轮下注后，界面自动显示下一轮下注区，直到达到上限。
- 进入连战时一次性确定整场本金 `S`，并锁定对应筹码；后续每轮只选择庄、闲或和，不重新选择金额。
- 下注区按从上到下的顺序连续生成。点击当前最后一轮相同的下注目标会撤销该轮，并保留前一轮及一个新的空白下注区；前面的轮次不能直接撤销。取消按钮会清空全部下注目标。
- 连战下注目标会组成连续的规划序列并投影到当前路势；信心结算按投影后的路势识别，不再用规划前的相反路势对同一规划重复施加逆势惩罚。
- 连战规划存在时，历史结果与最后一注之前的规划结果拼接后统一识别路型；规划序列的最后一注作为下一步预测目标，匹配则加成，预测相反则按统一规则逆势扣分。最后一注不参与预测自身。
- 每一轮目标独立保存，并同时投影到大路与珠盘路的预测虚影。
- 连战在桌面横屏中将 N 个牌局横向并排，并依照局数等分画面；无法完整容纳时等比压缩每局牌桌与播报，确保最多局数仍在同一横屏内完整显示。手机竖屏保持纵向排布以保证操作面积。
- 玩家可在任意未结算牌局上直接点击牌张操作，所有牌局独立保持发牌、开牌和播报状态，不会因操作另一局而中断动画。
- 牌局完成开牌后会标记当前结算结果，正常翻牌操作随即锁定，但符合条件的牌张仍可作为全局千术目标。未命中或非目标和局且仍可出千的牌局显示红色“危 · 可出千”状态。放弃为全局操作，放弃即结束整场连战并没收本场下注。
- 和局不算输、不产生赔率，从有效结算局数中移除。
- 任意有效局失败，整场连战失败，筹码全部没收。
- 有效局全部命中时，返还现金 `S × 2^K`，其中 `K` 为非和局数量；全部和局按 1 倍返还本金。
- 所有牌局都精确命中各自下注目标时，立即结束整场并结算现金。若全部牌局已结算但仍有败局或非目标和局，且仍有筹码与合法千术目标，则保留整场等待出千；筹码耗尽或已无合法千术目标时结束整场。

- 玩家进入牌桌后可以下注或旁观。门票、下注和出千全部消耗筹码，赌场赢款返还现金。
- 1 枚筹码面值为 100；现金不能兑换筹码。MVP 初始给予 10 枚筹码，之后由餐厅经营和荷官抵押奖励产出。
- MVP 支持庄、闲、和下注，但单轮暂时只允许选择一个下注区域，以保持开牌时的双方归属明确。
- 牌桌排版由上至下固定为荷官侧牌位、闲/和/庄下注区、操作按钮、筹码托盘和完整路单；下注与看路不再分列为两个页面区域。
- 玩家通过筹码数量滑块一次确定整场使用的筹码数，再为每轮点击一个下注目标；点击目标只负责确认或撤销该轮，不会重复追加筹码。
- 下注目标按轮次独立保存，但所有轮次使用相同的筹码数；确认前可以修改最后一轮或从最后一轮开始撤销。
- “取消”一次性清空本次所有下注目标；“确认”按滑块确定的筹码数扣除筹码并进入发牌。
- 下注金额受当前牌桌上下限和玩家可用筹码约束。
- 封盘后不能修改下注。
- 旁观不会进入 3D 牌桌。玩家留在当前下注页，纸牌从荷官侧直接移动到桌面上的闲、庄牌位并自动翻开，不使用运镜。
- 旁观动画先依次发初始四张并逐张翻开；只有初始牌面公开后，才按照真实补牌结果追加“发一张、翻一张”的补牌动画。
- 全部牌面公开后在当前牌桌覆盖显示庄闲点数和胜负，随后更新下方路单；旁观局不触发玩家逐张开牌或神助。
- 旁观局同样更新牌桌路单，但玩家身处赌场时餐厅停止营业。
- 正式下注后的 3D 桌面不重复显示押注区，只设置左侧闲家和右侧庄家的发牌放牌区。荷官侧先依次把初始四张牌发到两个桌内牌位，再用纯纸牌位移动画把玩家下注一方的整手牌推到近侧中央；不制作荷官模型。
- 发牌开始时，玩家已经确认的筹码按照实际面额和枚数显示在 3D 桌面的下注位置。赢钱时，赔付筹码从荷官侧推到玩家下注位置；输钱时，原下注筹码被收回荷官侧；和局时筹码退回玩家侧。筹码移交结束后才显示最终结算覆盖层。
- 补牌仍先发到所属方的桌内牌位。若补牌属于玩家下注的一方，发牌结束后继续滑到玩家面前，再进入现有的逐张选择开牌流程。
- 玩家咪牌功能暂时关闭。正式下注后，无论点击己方牌还是荷官牌，均从上方向目标牌垂直推进并自动翻开；不绕到牌桌另一侧，也不做大角度水平转向。神助检查和发动时机保持不变。
- 采用庄、闲均为两倍的设计赔率，不启用标准百家乐庄家抽水。

## 9. 搓牌体验

> 当前版本暂时停用玩家咪牌交互，玩家点击任意待开牌后均使用荷官式自动翻牌。以下内容作为后续恢复咪牌时的设计规格保留。

### 9.1 目标

搓牌是 MVP 中最重要的表现环节。其他场景可以简化，但搓牌必须提供清晰、可控并具有悬念的操作反馈。

### 9.2 基本交互

```text
从长边、左下角或短边附近按住
  -> 按下时吸附并锁定咪牌方向
  -> 沿锁定方向推进或回退
  -> 玩家按下开始咪牌时，手指占位物立即出现并遮住数字与花色
  -> 沿当前折线方向明确拖动，可单独移开手指
  -> 牌角逐渐卷起并露出牌面信息
  -> 推进到总进度 70% 后完全揭牌
  -> 未完成时松手，完全回弹并允许重新选择方向
```

玩家应能够分阶段看到边纹、局部点数和完整牌面，逐步排除可能结果。鼠标拖动距离与露出程度必须稳定对应，不能让随机动画取代操作。

- 三种方向以当前镜头为基准，固定为镜头左侧长边、左下角和靠近镜头的短边；庄闲两侧使用相同的屏幕方向。
- 每个方向拥有宽容的角度判定扇区；点击可以位于牌面之外，只要仍落在有效扇区内就视为选中。
- 按下后角度不再随鼠标横向摆动，垂直于推进轴的移动不改变进度。
- 进入咪牌特写镜头时不显示手指；每次按下开始操作时手指立即出现，随翻起的牌面运动。未完成松手回弹后手指消失，下一次按下重新出现。
- 开牌推进与移开手指使用互相垂直的两条输入轴。长边、左下角、短边三种咪牌方向分别拥有对应的手指移开方向。
- 只有连续移动达到明确距离，且移手指方向的分量显著大于开牌推进分量时，才锁定为移手指操作；锁定期间开牌进度冻结，避免正常咪牌误触。
- 拖动可以随时向前或向后；未完成时松开鼠标必定回到零进度，玩家可不限次数重试。

### 9.3 使用频率

- 普通牌允许点击或短拖快速翻开。
- 影响胜负的关键牌默认进入完整搓牌模式。
- 玩家可以主动选择快速开牌，避免重复操作造成疲劳。
- MVP 可以省略荷官角色和手部骨骼动画。

### 9.4 反馈组成

- 纸牌弯曲与回弹；
- 牌面分阶段显露；
- 接触阴影和轻微桌面反馈；
- 与拖动速度对应的摩擦音；
- 完全揭牌时的明确视听反馈。

### 9.5 实时牌势与末张判势

- 当前玩法验证构建暂时隐藏末张判势栏；以下规则和计算逻辑保留，待后续重新开放界面时继续使用。
- 开牌过程中持续显示庄、闲双方当前已公开点数，并标记领先、落后或同点以及点差。
- 当前发牌阶段只剩最后一张暗牌时，按所有真实牌面列出该牌将导致的即时结果：赢、输、和、闲补牌或庄补牌。
- 候选牌按真实牌面显示为 `A、2–10、J、Q、K`；`10/J/Q/K` 明确标为同一组 0 点牌，不再使用单独的“0”牌面代替字母牌。
- 连续牌面得到相同判势时合并为区间，例如 `4–9` 全部导致闲补牌时只显示一个“4–9 · 闲补牌”结果。
- 赢输以玩家当前下注方向为准；旁观时直接显示庄赢或闲赢。
- 判势只允许读取已公开牌和玩家正在揭示的牌位，不得使用其他暗牌的预生成点数。
- 尚有多张暗牌导致结果不确定时不显示确定性结果表。

## 10. 餐厅经营

餐厅完全通过 2D 管理界面呈现，不制作角色移动、装修摆放或生产动画。

餐厅不再直接产出现金。每个经营周期进行一次筹码产出判定：

| 等级 | 成功率 | 成功产出 |
|---|---:|---:|
| 1 | 35% | 1 枚筹码 |
| 2 | 52% | 1 枚筹码 |
| 3 | 68% | 2 枚筹码 |
| 4 | 82% | 3 枚筹码 |

餐厅可以重复抵押。每次抵押获得筹码并增加抵押债务，抵押额度受当前餐厅估值限制；赎回需要支付累计债务的 2.5 倍现金。抵押不设固定次数，但不能超过剩余估值。

### 10.1 功能

1. **升级**：投入现金，提高餐厅等级和周期筹码产出。
2. **周期收益**：餐厅正常经营时，每个经营周期按概率产生与等级对应的筹码。
3. **典当**：立即获得一笔筹码，餐厅停止产生收益并累计现金赎回债务。

### 10.2 周期规则

游戏拥有独立的世界时间，用于后续日程、事件和营业安排：

- 每个游戏日固定为 24 小时，跨过 24:00 后进入下一日；
- 赌场外每经过 1 秒现实时间，推进 1 小时游戏世界时间；
- 进入赌场大厅、牌桌或开牌流程后，每经过 1 秒现实时间，推进 1 分钟游戏世界时间；
- 世界时间不会改变牌桌倒计时、动画、神助小游戏等现实计时逻辑；
- 在牌桌上等待玩家操作的阶段暂停世界时间，包括下注、选择开牌方、眯牌、神助操作与确认、结算确认；其他现实计时不暂停；
- 餐厅正常营业时间为每日 08:00 至 20:00，每累计 1 小时有效经营时间结算一次当前等级收益；
- 玩家进入赌场后餐厅停止产生收益，已累计的经营周期进度冻结；离开赌场并回到有效营业活动后继续累计；
- 玩家在餐厅内到达 20:00 时暂停时间并选择“收工回家”或“继续营业”。继续营业会维持经营至下一次 20:00；
- 餐厅已经打烊时，进入餐厅不会自动开门，世界时间暂停。玩家可主动选择继续营业，随后时间和收益恢复，并持续到下一次 20:00；
- 自宅中世界时间停止；返回地图只切换操作界面，不改变当前活动，选择其他地点后才真正切换活动；
- 地图和自宅在 06:00 至 18:00 使用白天背景，其余时间使用夜间背景，昼夜图片以交叉淡入淡出切换。

赌场内外的时间流速只服务于世界日程，不改变现实计时的牌桌和小游戏节奏。

### 10.3 休息与睡眠不足

- 每天 00:00 增加 8 小时内部缺觉量，该数值可以累积，并只能通过实际休息时长等量减少；玩家界面不显示精确数值，只显示“不太困、有点困、很困、困得厉害、快撑不住了”等生活化状态。
- 自宅床铺提供“睡到自然醒”和“睡到明早 08:00”两个选项；点击菜单外区域可以关闭休息菜单。
- 内部缺觉量不足 1 小时时不能选择自然醒。自然醒会持续到当前缺觉量清零；如果过程中跨过 00:00，新增的 8 小时也计入本次所需休息时长。
- “睡到明早 08:00”固定推进到下一日 08:00，按实际时长恢复，未睡够的部分继续保留。
- 内部缺觉量达到 10 小时后的“睡眠不足”惩罚流程暂未启用；睡眠债务仍会累计并可通过休息清除。启用后才会在最近的 08:00触发晕倒规则。
- 醒来提示必须显示本次实际休息时长，并用“睡够了/还是没有睡够”等玩家语言反馈结果，不向玩家展示“睡眠债务”等内部术语。

### 10.4 典当规则

- 典当前必须显示立即获得的金额与失去的周期收益。
- 典当后餐厅进入“已典当”状态并停止经营。
- MVP 可以暂不提供赎回，但数据模型必须保留扩展空间。
- 餐厅已典当且流动资金耗尽时触发 Game Over。

## 11. MVP 内容范围

### 11.1 必须包含

1. 两座赌场，建议分别拥有 4 桌和 6 桌。
2. 每桌独立运行牌局、历史结果和状态。
3. 图形化赌场大厅与可选择的牌桌。
4. 珠盘路、大路及大厅压缩预览。
5. 庄、闲下注和旁观。
6. 完整百家乐点数、发牌与补牌规则。
7. 长庄、长闲、单跳三种基础路势。
8. 至少三项对应技能，真实改写结果概率。
9. 关键牌的 3D 搓牌与快速开牌。
10. 餐厅升级、周期收益和典当。
11. 统一资金结算与 Game Over。
12. 概率、路势、技能和牌局结果调试工具。
13. 地图式场景导航、基础昼夜切换、餐厅日程和自宅休息。
14. 桌面与移动端分别排版，并在咪牌拖动时阻止页面滚动。

### 11.2 暂不包含

- 完整肉鸽旅程终点；
- 剧情、NPC 和正式角色成长体系；
- 3D 赌场大厅和后台桌 3D 画面；
- 餐厅装修与生产表现；
- 联机、账号和服务端同步；
- 荷官模型和复杂手部动画；
- 正式存档与跨设备同步；
- 移动端专项性能优化与完整设备覆盖。

## 12. 验证目标

MVP 需要回答以下问题：

1. 玩家是否愿意在多桌之间观察、比较并换桌？
2. 玩家能否理解珠盘路、大路和三种基础路势？
3. 不同技能是否会改变玩家偏好的牌桌和下注行为？
4. 玩家是否相信路势与技能确实生效，同时接受优势局仍可能失败？
5. 搓牌是否比直接翻牌显著增强悬念，且不会在重复使用后造成疲劳？
6. 餐厅是否会产生“投入长期资产还是保留赌本”的真实取舍？
7. 典当餐厅是否成为有压力的最后手段，而非最优常规策略？

建议在试玩中记录换桌次数、观察局数、下注比例、技能触发后的下注变化、快速开牌使用率、餐厅升级时点和典当时点。

## 13. 当前待定事项

- 两座赌场的正式名称、美术主题和具体数值；
- 初始资金、下注上下限和赌场门票的最终平衡；
- 餐厅等级、升级成本、周期长度、收益和典当价格；
- 路势偏移和技能偏移的具体强度；
- 技能触发与叠加规则；
- 和局与对子投注范围；
- 赌场筹码产出与现金返还的最终平衡；
- 玩家离开赌场时是否存在资金转移限制；
- 单次肉鸽旅程的结构与最终目标。
